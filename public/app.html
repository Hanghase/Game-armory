CurseForge (Modpacks: atm10, atm11)

Was die Armory braucht: einen Application API Key. Nicht den Studio-Key — der funktioniert hier nicht.

  1. Bei curseforge.com einloggen.
  2. authors.curseforge.com → Settings → API Tokens.
  3. Create Token → der Key wird nur einmal angezeigt. Sofort kopieren und hier einfügen; er lässt sich danach nicht erneut anzeigen.
  4. Oben unter „CurseForge API-Key“ einfügen und Speichern. Die Armory prüft den Key sofort live gegen die API — ein falscher Key wird abgelehnt, nicht stillschweigend gespeichert.

Ohne Key: Modpack-Suche und automatische Update-Prüfung entfallen. Installieren per ZIP-Upload geht weiter. Die Versionsanzeige bleibt grau, bis eine Soll-Version von Hand eingetragen ist. Ist der Schlüssel ein $2a$…-String, ist es ein Studio-Key — abgelehnt.

Steam (7 Days to Die)

Für die Installation: kein Key nötig. SteamCMD lädt anonym, solange das App kein Login verlangt (bei 7d2d der Fall).

Für die Update-Prüfung: Die Armory liest den lokalen Build aus steamapps/appmanifest_294420.acf. Der offizielle Vergleichs-Endpunkt (ISteamApps/UpToDateCheck) antwortet für dieses App mit version_is_listable: false — er ist also nicht nutzbar. Deshalb bleibt 7d2d grau, statt fälschlich „veraltet“ zu behaupten.

GitHub (TeamSpeak 6)

Kein Key nötig. Die Armory liest die öffentliche /tags-Schnittstelle. Ein Tag ist der ausgelieferte Stand — auch ohne Release. Das Rate-Limit (60 Abfragen/Stunde pro IP) reicht bei einem Prüfintervall ab 15 Minuten problemlos.

Tags können umbenannt werden. Passt das Format danach nicht mehr zur installierten Version, bleibt die Anzeige grau statt fälschlich „veraltet“.

Armory selbst

Das Panel aktualisiert sich auf einen Release-Stand. Es wechselt dabei auf einen Tag (unveränderlicher Stand), sichert vorher den alten Zustand und rollt automatisch zurück, wenn das Panel danach nicht antwortet. Datenbank, Passwörter und Swords bleiben unberührt.

Deine Server

Versionen der Swords gegen ihre Quelle prüfen (Steam, GitHub, CurseForge). 0 = nur auf Knopfdruck.

Was die Farben bedeuten

grün — Quelle bestätigt: installierte Version ist aktuell.
gelb — Quelle oder Soll-Version meldet eine andere Version; die neuere steht daneben.
grau — keine belastbare Aussage möglich. Der Tooltip nennt den Grund.

Grau ist kein Fehler. Es heißt: die Armory weiß es nicht — und sagt das, statt zu raten.

Ein Rack ist die Schablone (Spiel, Loader, Install-Quelle). Der daraus erstellte Server heißt Sword.

1. Modpack suchen

Noch keine Suche.

Es werden nur Minecraft-Modpacks durchsucht.

Neueste zuerst. release beta alpha

Serverpack-ZIP auf dem Server

Die ZIP muss bereits auf dem Server liegen (z.B. unter /root/packs/). Es wird nichts hochgeladen.

ZIP-Datei hochladen

Archiv hierher ziehen oder klicken zum Auswählen

Die Datei wird geprüft, einmalig für diesen Vorgang verwendet und danach automatisch gelöscht. Akzeptiert: .zip, .tar.gz, .tar.xz, .tar.bz2, .tgz und .txz, maximal 2 GB.

SteamCMD-Installation

Dieses Rack wird per SteamCMD installiert (z. B. 7 Days to Die). Fehlt SteamCMD auf dem Server, wird es beim Start automatisch eingerichtet.

Sword

Ziel-Pfad: Wurzel für die Instanz (aus dem Rack vorbelegt, überschreibbar). Der Server landet unter <Ziel-Pfad>/<id>.

id: ^[a-z0-9][a-z0-9-]{1,30}$

Bei laufendem Server wird dieser vor dem Update gestoppt und danach nicht automatisch gestartet.

…
Admin-Schlüssel (nur EINMAL sichtbar)
Mit diesem Schlüssel im TeamSpeak-Client den Server als Admin übernehmen. Danach ist er ungültig.

Sword entfernen

Der Server wird dafuer zuerst gestoppt. Danach werden systemd-Unit, Sword-Datei und Logs entfernt.

EULA nachtragen

Ohne akzeptierte EULA startet der Server nicht.

Version eintragen

Keine Version automatisch erkannt? Dann hier von Hand eintragen, z.B. 8.1, 6.0.0-beta13.1 oder neoforge 21.1.251.

Nur für Quellen, die nicht selbst abfragen können (CurseForge ohne API-Key). Ist sie eingetragen, wird dagegen verglichen: gleich = grün, anders = gelb. Leer lassen = keine Soll-Version, Anzeige bleibt grau.

Die Projekt-Nummer des Modpacks auf CurseForge, z.B. 123456. Sie steht nicht im Serverpack und muss einmal von Hand eingetragen werden. Nur nötig, wenn der Versionsstand direkt bei CurseForge abgefragt werden soll — dafür braucht es zusätzlich einen eigenen API-Key in den Einstellungen.
